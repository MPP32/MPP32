# About this project

MPP32 is a payment layer for AI agents — an MCP server, federated catalog of
machine-payable APIs, x402 settlement engine, and analytics dashboard.

The project is maintained by a small core team operating under the `MPP32`
GitHub identity.

## Engineering

Development is AI-augmented. We use modern coding assistants as a core part
of our workflow and ship faster because of it. Every change is reviewed,
typechecked, and verified against the live catalog of 8,000+ services
before release.

## Commit identity

Earlier commits in this repository surface author identities reflecting the
development environments used to author them. From this point forward, all
commits are authored under the `MPP32` maintainer identity and signed —
signature verification is visible on every commit page on GitHub.
